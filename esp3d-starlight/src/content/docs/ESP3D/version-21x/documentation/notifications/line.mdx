[Line](https://line.me) is a free service but now line notify is discontinued and may not work anymore.

Considering you have a Line account and you already installed Line on your phone or PC:

1. Go to https://notify-bot.line.me/my/ and connect with email and password  
   ![Line notify login](/img/notifications/line/logon.png)

2. Once connected you will be able to generate a token   
   ![Line token generation](/img/notifications/line/generate.png)

3. Type token name on top, select recipient(s) and press Generate token   
   ![Line token name input](/img/notifications/line/generate2.png)

4. Once the token is created you need to copy it   
   ![Line user token](/img/notifications/line/token1.png)

5. You can create as many tokens as you want, and delete the ones you do not need   
   ![Line token management](/img/notifications/line/tokenmanagement.png)

6. Save the generated token in ESP3D, and set LINE as notification supplier  
   `[ESP610]type=LINE T1=xxxxxxxxxxxxxxxxxx`

7. Type `[ESP610]` to verify (T1 won't be displayed)

8. Try to send a message:  
   `[ESP600]Hi there, test from ESP3D`
