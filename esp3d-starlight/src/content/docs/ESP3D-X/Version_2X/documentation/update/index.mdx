# Update

ESP3D-X supports firmware and WebUI updates via SD card or OTA.

## SD Card Update

Place the firmware binary on the SD card and use the on-screen update menu.

## OTA Update

When WiFi is enabled, firmware updates can be performed over-the-air.

## Customization files

The same SD card mechanism applies theme colors, sounds, language packs, icons, logo and fonts — see [Customization](/esp3d-x/version_2x/documentation/customization/).

## Commands

- [ESP402](/esp3d-x/version_2x/documentation/commands/esp402/) — Check update at boot state
