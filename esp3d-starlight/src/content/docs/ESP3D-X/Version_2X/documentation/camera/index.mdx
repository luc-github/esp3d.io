# Camera

ESP3D-X supports camera modules on compatible ESP32 boards (e.g., ESP32-S3 WROOM CAM).

## Commands

- [ESP170](/esp3d-x/version_2x/documentation/commands/esp170/) — Camera control
- [ESP171](/esp3d-x/version_2x/documentation/commands/esp171/) — Save frame

## Supported modules

- ESP32-CAM (OV2640)

<aside class="warning-panel" data-icon="alert">
  <h4>Pre-alpha documentation</h4>
  <p>Camera support is still in development for ESP3D-X.</p>
</aside>
