# Compilation

## Prerequisites

- [ESP-IDF 5.4.x](https://docs.espressif.com/projects/esp-idf/en/v5.4/esp32/get-started/index.html)
- Python 3.8+

## Build

```bash
python build_all.py --list
python build_all.py 8mb_wifi_fluidnc
```

See [Installation](/esp3d-x/version_2x/installation/) for more details.
