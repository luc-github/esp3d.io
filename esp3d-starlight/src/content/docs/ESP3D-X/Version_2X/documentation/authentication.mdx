# Authentication

ESP3D-X supports optional authentication to protect access to the device.

## Levels

- **Admin** — Full access to all commands and settings
- **User** — Limited access (can view status, cannot change critical settings)
- **Guest** — Read-only access

## Commands

- [ESP550](/esp3d-x/version_2x/documentation/commands/esp550/) — Set admin password
- [ESP555](/esp3d-x/version_2x/documentation/commands/esp555/) — Set user password

## Recommendations

Always enable authentication if your device is accessible from a public network.
