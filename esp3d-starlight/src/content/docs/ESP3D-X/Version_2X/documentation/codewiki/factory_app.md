# factory_app (hub)

Page-hub pour la **factory application** (application d'usine) et le bootloader personnalise. La factory app est documentee par carte dans les modules ci-dessous ; les documents `factory_*` decrivent les sous-systemes communs (entrees, affichage, stockage, mises a jour OTA/sd, snapshot). Voir aussi la documentation de conception du depot : [factory_app_technical_doc](https://github.com/luc-github/Pibot-cnc-pendant-firmware/blob/main/docs/Factory/factory_app_technical_doc.md).
