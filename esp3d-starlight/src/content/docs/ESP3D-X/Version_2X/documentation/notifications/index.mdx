# Notifications

ESP3D-X can send push notifications when events occur (e.g., print finished, alarm).

## Supported services

- [Email / SMTP](/esp3d-x/version_2x/documentation/notifications/email_and_smtp/)
- [Pushover](/esp3d-x/version_2x/documentation/notifications/pushover/)
- [Telegram](/esp3d-x/version_2x/documentation/notifications/telegram/)
- [IFTTT](/esp3d-x/version_2x/documentation/notifications/ifttt/)
- [WhatsApp](/esp3d-x/version_2x/documentation/notifications/whatsapp/)

## Commands

- [ESP600](/esp3d-x/version_2x/documentation/commands/esp600/) — Send notification
- [ESP610](/esp3d-x/version_2x/documentation/commands/esp610/) — Configure notification settings
