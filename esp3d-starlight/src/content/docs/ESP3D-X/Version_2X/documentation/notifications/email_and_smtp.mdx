# Email & SMTP

Send email notifications via your SMTP server.

## Configuration

Use [ESP610](/esp3d-x/version_2x/documentation/commands/esp610/) with `type=EMAIL` to configure SMTP settings.

## Requirements

- SMTP server address and port
- Authentication credentials (if required)
