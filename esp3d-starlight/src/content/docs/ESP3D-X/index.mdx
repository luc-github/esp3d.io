### What is ESP3D-X ?

ESP3D-X is the next-generation firmware for ESP32-based pendants with TFT displays, designed as the successor to **ESP3D-TFT**.

It provides a comprehensive touchscreen and physical control interface for **CNC machines** running FluidNC or grblHAL, and is architected to eventually support 3D printers as well.

ESP3D-X is built on the **ESP-IDF 5.4.x** framework and uses **LVGL 9.2.x** for the user interface, offering a modern, responsive, and highly configurable experience.

<aside class="warning-panel" data-icon="alert">
  <h4>Pre-alpha status</h4>
  <p>ESP3D-X is currently in <strong>pre-alpha</strong> stage. Features, APIs, and hardware support may change significantly. Feedback and contributions are welcome.</p>
</aside>

### Current state

- **Version:** 2.0 (pre-alpha)
- **Primary supported board:** [PiBot CNC Pendant V1](/esp3d-x/version_2x/hardware/pibot-pendant-v1/)
- **Supported machine firmwares:** FluidNC, grblHAL(On Going), Marlin (To be done), Repetier (To be done), Smoothieware (To be done),
- **Additional boards:** Support for more boards will be ported progressively

### Cybersecurity concerns

<aside class="info-panel">
  <h4>Cybersecurity</h4>
  <p>If you plan to have access to your ESP from outside of your private network, then you need to apply some basic security rules to avoid anybody being able to access your ESP.</p>
</aside>
<aside class="warning-panel" data-icon="alert">
  <h4>Disclaimer</h4>
  <p>This is for reference — you are responsible for your board and internet network; we are not responsible for any damage to any of your network appliances.</p>
</aside>
<aside class="info-panel" data-icon="info">
  <h4>Recommendations</h4>
  <p>Following steps must be done before your ESP is visible from public internet:</p>
  <ul>
    <li>Activate authentication in configuration file before flashing</li>
    <li>Change default user and password (this can be done with commands or web UI)</li>
  </ul>
  <p>It is also strongly recommended to:</p>
  <ul>
    <li>Use strong passwords</li>
    <li>Use unique passwords, not the same as for other accounts</li>
    <li>Change password regularly</li>
    <li>Configure your box to redirect a different port than 80 to the port 80 of ESP</li>
  </ul>
</aside>
