### What is ESP3DLib ?

ESP3DLib is a Marlin library for ESP32 boards using Marlin 2.x. that enable ESP3D features like WiFi and WebUI.
Features depends on the version the ESP3DLib installed.

Marlin use arduino framework and platformio system

### Tested boards 

The list is [here](./Version_1.X/hardware/) for 1.0, and [here](./Version_3.X/hardware/) for 3.0

Please refer to Marlin documentation for more information on specific configurations for each boards.

### Cybersecurity concerns

<aside class="info-panel">
  <h4>Cybersecurity</h4>

  <p>If you plan to have access to your ESP from outside of your private network, then you need to apply some basic security rules to avoid anybody being able to access your ESP.</p>
</aside>
<aside class="warning-panel" data-icon="alert">
  <h4>Disclaimer</h4>

  <p>This is for reference ??you are responsible for your board and internet network; we are not responsible for any damage to any of your network appliances.</p>
</aside>
<aside class="info-panel" data-icon="info">
  <h4>Recommendations</h4>

  <p>Following steps must be done before your ESP is visible from public internet:</p>
  <ul>
    <li>Activate authentication in configuration file before flashing</li>
    <li>Change default user and password (this can be done with commands or web UI)</li>
  </ul>

  <p>It is also strongly recommended to:</p>
  <ul>
    <li>Use strong passwords</li>
    <li>Use unique passwords, not the same as for other accounts</li>
    <li>Change password regularly</li>
    <li>Configure your box to redirect a different port than 80 to the port 80 of ESP</li>
    <li>Use the DMZ feature of your box</li>
  </ul>
</aside>
<aside class="info-panel" data-icon="tip">
  <h4>Additional tips</h4>

  <p>Remember the web server is not HTTPS, this means the server will never be fully secure. In particular, avoid connecting to your printer from any public network you do not own. Stick to your 4G network or other safe places to avoid MITM attack.</p>
</aside>
